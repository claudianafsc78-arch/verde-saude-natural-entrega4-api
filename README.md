# 🌿 Verde & Saúde Natural — Implementação da API

## Sobre o projeto

API Back-End desenvolvida para o sistema Verde & Saúde Natural, uma plataforma de produtos naturais que permite gerenciar clientes, produtores, produtos e pedidos.

## Tecnologias utilizadas

- Java 21
- Spring Boot 4.0.8
- Spring Web
- Spring Data JPA
- H2 Database
- Maven

## Tarefas implementadas

| Código | Tarefa | Verificação |
|---|---|---|
| API-01 | Estrutura inicial da API | Inicialização do Spring Boot |
| API-02 | Configuração do banco de dados | Conexão com H2 |
| API-03 | Cadastro de clientes | Postman — POST e GET |
| API-04 | Cadastro de produtores | Postman — POST e GET |
| API-05 | Produtos orgânicos | Postman |
| API-06 | Catálogo de produtos | Postman — consulta |
| API-07 | Registro de pedidos | Postman — POST |
| API-08 | Consulta e atualização de pedidos | Postman — GET e PUT |

## Testes realizados

- Testes de endpoints utilizando Postman.
- Testes de cadastro e consulta de dados.
- Testes de registro e atualização de pedidos.
- Testes automatizados com resultado `BUILD SUCCESS`.
